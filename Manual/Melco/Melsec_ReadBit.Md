# コマンドリファレンス：Melsec_ReadBit

## 概要

**Melsec_ReadBit** は、三菱電機 MELSEC シーケンサ（計算機リンクユニット / 通信ポート）に対してビット単位の一括読出要求（`BR` コマンド）を実行し、取得した ON/OFF 状態（`1`/`0`）を指定の変数またはセルへ格納する高水準通信コマンドです。

複雑な計算機リンクのデバイスコード指定（`X0010` 等）やプロトコルフレーム（形式 1 〜 5）、ヘッダ/フッタおよびサムチェック計算を意識することなく、`"X10"` や `"M100"` といった直感的なデバイス表記で通信を行うことができます。

> 💡 **補足**: 内部で使用される専用プロトコル形式（P1 / P2 / P3 / P4 / P5）および伝送待ち時間は、[Melsec_Mode](Melsec_Mode.Md) コマンドで設定された値（未指定時は P1 / 待ち時間 0ms）に自動追従します。

### 🔄 対象ビットデバイス仕様

| デバイス種別 | 表記例 | デバイスコード変換 | アドレス進数 |
| :--- | :--- | :--- | :--- |
| 入力リレー | `X0` / `X10` | `X0000` / `X0010` | 16 進 |
| 出力リレー | `Y0` / `Y10` | `Y0000` / `Y0010` | 16 進 |
| 内部リレー | `M100` | `M0100` | 10 進 |
| ラッチリレー | `L20` | `L0020` | 10 進 |
| リンクリレー | `B10` | `B0010` | 16 進 |
| タイマ接点 | `TS0` | `TS0000` | 10 進 |
| カウンタ接点 | `CS0` | `CS0000` | 10 進 |

## 💡 書式・パラメータ仕様

### コマンド構文

```csv
,SEQUENCE, [ステップキー], Melsec_ReadBit, [Device], [Points], [ResultKey], "[StationNo: 00]"
```

### パラメータ（引数）一覧

| 引数位置 | 引数名 | 必須/任意 | 説明・制約 |
| :--- | :--- | :---: | :--- |
| 第 1 引数 | `Device` | **必須** | 読み出しを開始する先頭ビットデバイス名（例: `"X0"`, `"Y10"`, `"M100"`, `"L20"`, `"B10"`, `"TS0"`, `"CS0"`）。 |
| 第 2 引数 | `Points` | **必須** | 連続して読み出すビット点数（`1`〜`256` の整数）。 |
| 第 3 引数 | `ResultKey` | **必須** | 読み出したビット列（カンマ区切り、例: `"1,0,1,0"`）を格納する変数キー名またはセル参照。 |
| 第 4 引数 | `StationNo` | 任意 | 送信先の局番 2 桁 16 進文字列（省略時既定値: `"00"`、自局 PC 番号 `"FF"` は自動補完）。 |

## 🔄 特殊置換規約・分岐規約の適用

本コマンドの引数における特殊記法および解釈ルールです。
* **動的置換（`$`）**: 引数内で `$PARAMキー$` のように記述すると、実行時に変数プール（PARAM）の値へ動的置換されます。（適用可能な引数: 全引数対応）
* **ジャンプ先指定（`#`）**: 本コマンドはジャンプ制御を行わないため適用されません。（適用可能な引数: 非適用）
* **共通コマンド指定（`@`）**: 本コマンドは外部マクロを呼び出さないため、共通コマンド呼び出し記法は適用されません。（適用可能な引数: 非適用）
* **カンマのエスケープ**: 通信条件文字列（例: `"9600,E,7,1"`）や複数データのカンマ区切り値を単一引数として渡す場合は、必ず `"..."` と二重引用符で囲んで記述します。
* **エイリアス（別名）**: `Analysis_Melsec_ReadBit`, `Sqn_Melsec_ReadBit`

## 💡 動作例（正しい構文での記述例）

### スクリプト記述例

※COMMAND ブロック配下の子要素行（PARAM, SEQUENCE）は必ず行頭カンマから開始し、スペースインデントや行末コメント（`;`）は記述しないでください。

```csv
COMMAND, "MELSEC_READ_BIT_DEMO", "BIT_STATUS"
,PARAM, "BIT_STATUS", Work, "ビット読出結果", ""
,SEQUENCE, 010, Melsec_Mode, "9600,E,7,1", "NONE", "P1"
,SEQUENCE, 020, Melsec_Open
; M100 から 8 点のビット状態を一括読出し BIT_STATUS へ格納（局番 00）
,SEQUENCE, 030, Melsec_ReadBit, "M100", 8, "BIT_STATUS", "00"
,SEQUENCE, 040, Melsec_Close
,SEQUENCE, 050, Exit
```

### 実行時の挙動・変数変化

* **実行前の状態**: MELSEC 計算機リンク回線がオープン済みで、`"BIT_STATUS"` が空文字列 `""` の状態。
* **実行後の状態**: ステップ `030` の実行により `M100`〜`M107` の 8 ビット読出要求（`BR` コマンド）が送受信され、ON/OFF ビット文字列（カンマ区切り、例: `"1,0,1,1,0,0,0,1"`）が `"BIT_STATUS"` に格納されます。

## 🚫 エラーハンドリング・安全設計（仕様制限）

入力データの異常や実行時エラーに対し、解析・実行エンジンが実行するセーフティ規約です。

1. **引数範囲・プロトコル書式バリデーション保護**:
   - 必須引数の欠落、デバイス表記・数値範囲の不正、または余剰引数が指定された場合は `_log.LogError` に詳細を記録し、`SetErrorAndHalt` により異常電文の送出を未然に遮断します。
2. **通信タイムアウト・異常応答・排他ドメイン保護**:
   - 相手機器の無応答タイムアウト、NAK／異常終了コード応答、または他通信ドメインとの排他競合が発生した場合は、例外クラッシュを起こさず安全にエラーハンドリングを行います。

## 🧪 ユニットテスト仕様

本コマンドクラス（`Melsec_ReadBitCommand.cs`）に実装されている `RunUnitTest()` メソッドが検証するユニットテストの仕様です。

### テスト実行前提条件

* **実行トリガー**: `RunUnitTest()` メソッドの呼び出し
* **有効化条件**: システム全体の最小ログレベル（`ErrorLogger.MinimumLevel`）が `LogLevel.Test` であること（それ以外の場合は無効化ガードにより早期リターン）
* **検証結果出力**: `_log.LogTest` によるログ出力。検証失敗時は `_log.LogError`、予期せぬ例外発生時は `_log.LogCritical` で記録し、`finally` ブロックで `Melsec_ModeCommand.DefaultProtocolType` および `UartTransportCore.Shared.IsSimulationMode` を開始前の状態へ復元します。

### テストケース一覧

| No | テストカテゴリ | テスト条件（入力値） | 期待される結果（出力値） | 検証の目的 / 観点 |
| :---: | :--- | :--- | :--- | :--- |
| **1** | 正常系 | `IsSimulationMode = true`・`DefaultProtocolType = "P4"` 環境下で引数 `"M100"`, `"4"`, `"RES_M"`, `"00"` および擬似応答（`STX + "00FF1011" + ETX + SUM + CRLF`）を与えて実行 | `!param.HasError` かつ `param.IsCommandGo == true`、格納先 `SBuf["RES_M"]` が `"1,0,1,1"` と一致する | `BR` ビット一括読出フレーム構築・形式 4 応答解析・カンマ区切り格納の検証 |
| **2** | 異常系 | 点数範囲外（`1`〜`256` 外）、デバイス空指定、NAK／無応答（`"ERROR_RESPONSE"`）、または受信データ長不足（`"ERROR_LENGTH"`） | エラー識別子を `ResultKey` へ格納し、`_log.LogError` 出力と `SetErrorAndHalt` により安全に停止する | 点数境界チェックおよび NAK・ビット長異常時のフェイルセーフ検証 |
